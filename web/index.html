      How it works

      A classic NLP pipeline built for Sindhi's Perso-Arabic script, plus a neural translator.

      1. NormalizeUnicode NFC, Arabic/Urdu/Persian look-alikes folded (ى ی → ي, ك → ڪ, ہ → ه), optional vowel marks ignored.
      2. TokenizeArabic-script word runs with their character offsets, plus multi-word headwords like اک ڇنڀ.
      3. DetectA word is fine if it's in the 58k-word lexicon, is a common word in 53M tokens of Sindhi text, or is in your own word list.
      4. GenerateSymSpell finds every word within 2 edits in milliseconds.
      5. RankSindhi-weighted edit distance (cheaper for letters that differ only by dots, or that sound alike), log frequency and a bigram language model over the neighbouring words. The top 3 are shown.
      6. TranslateNLLB-200 (600M, int8 via CTranslate2) for sentences; the lexicon for single words.
